# Одинаковая проверка пяти моделей

Протокол зафиксирован до запуска: внешняя StratifiedGroupKFold CV (5 частей), два повтора, seed 2026.
Внутри каждого train — StratifiedGroupKFold (3 части) для выбора параметров по balanced accuracy.
Модели: Dummy, L1, RF, L1 -> 20 признаков -> RF, AE -> 32 признака -> RF.
Все модели получают одинаковые внешние train/test и внутренние folds.
Scaler, L1-отбор и AE обучаются только внутри соответствующего train.
Внутренний LogisticRegressionCV заменён обычной L1 с C в общей сетке:
это позволяет обучать scaler отдельно внутри каждого внутреннего fold.

Сетка L1: C=0.1,1,10. RF: 200 деревьев, max_depth=6/None,
min_samples_leaf=1/3, class_weight=balanced. Это новая компактная сетка,
общая для всех RF-вариантов; она отличается от прошлых одиночных запусков.
Архитектура AE фиксирована: 114-64-32-64-114, ReLU, линейный выход,
Adam/MSE, 50 эпох. Пороги отдельно не настраиваются, используется predict.
L1-классификатор без class_weight, как в исходной работе.
TOP-20 ранжируется по абсолютным коэффициентам; число ненулевых сохраняется.

Это внутренняя разведочная оценка: данные и методы уже изучались раньше.
Повторы и folds зависимы, SD — описательный разброс, не доверительный интервал.
Внешняя клиническая валидация не проводилась. Окончательную модель для
приложения этот скрипт не выбирает и не обучает на всей выборке.

Запуск: python eeg_anomaly_detection/13_nested_comparison.py
Каждый завершённый fold сохраняется отдельно; повторный запуск пропускает
готовые folds. После изменения протокола нужно использовать новую папку.

До завершения первого fold обнаружены две пары одинаковых AB-профилей.
Первая попытка остановлена. Текущий протокол держит одинаковые профили
в одной группе и во внешних, и во внутренних разбиениях. Разметка сохранена.
У одной пары различаются диагнозы. Это ограничение качества данных.
