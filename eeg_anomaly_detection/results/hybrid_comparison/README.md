# Автоэнкодер и Random Forest

Запуск из корня: python eeg_anomaly_detection/12_hybrid_comparison.py

TensorFlow/Keras, Adam, MSE, 50 эпох, batch 32, seed 42.
Размеры: 114 -> 64 -> 32 -> 64 -> 114. ReLU в скрытых слоях,
линейный выход для стандартизированных признаков.
Обучение представления на всех участниках обучающей части без использования
меток; RF использует метки. Scaler и AE переобучаются внутри каждого fold.
Сетка RF и разбиения совпадают с шагом 08. Обучение выполняется пакетами
через train_on_batch. В pipeline сохраняются веса encoder; при предсказании
два слоя ReLU вычисляются NumPy, без загрузки TensorFlow.

Это разведочный результат на уже просмотренном тесте, не внешняя валидация.
Латентные компоненты не имеют прямых названий электродов или ритмов.
Клиническая пригодность и устойчивость на новых выборках не установлены.
Проверены размер (120,32), конечность признаков и совпадение предсказаний
после повторного чтения сохранённой модели.
