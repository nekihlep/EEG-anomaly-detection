# Проверка отбора признаков

Запуск: `python eeg_anomaly_detection/08_random_forest.py` из корня проекта.

Сравниваются RF на всех 114 признаках и RF после L1-отбора 20 признаков.
Используется исходное стратифицированное разбиение 80/20, seed 42.
Масштабирование и L1 обучаются заново внутри каждой обучающей части CV.
Параметры RF выбираются по balanced accuracy; для двух вариантов сетка одинакова.
L1 выбирает C по внутренней 5-fold CV. TOP-20 — по абсолютным коэффициентам;
если ненулевых коэффициентов меньше 20, в набор могут войти нулевые.

Файлы features содержат реальные имена столбцов и исходные индексы.
Файлы predictions содержат индекс строки датасета и предсказания.
0 — пациент, 1 — здоровый; patient_score относится к классу пациентов.
Pipeline сохраняется локально в pickle, включая scaler и selector.
Старые сохранённые модели не перезаписываются.

Это промежуточная проверка на уже просмотренном тесте, не независимая
финальная оценка. Старые графики важности в results/figures ещё не обновлены.

В этом запуске liblinear выдал ConvergenceWarning; в финальном L1 CV
максимальное n_iter_ достигло 5000. Выбран C=21.5443469.
Отбор содержит 20 ненулевых коэффициентов. Сходимость требует отдельной
проверки перед использованием результатов в статье.
