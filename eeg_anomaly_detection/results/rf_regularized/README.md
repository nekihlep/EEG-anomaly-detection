# Повторная проверка L1

Сетка C: 0.01, 0.1, 1, 10, 100. Выбрана более регуляризованная сетка
после предупреждения при C=10000 в старой сетке. Это изменение эксперимента,
а не только увеличение лимита итераций. Тест не использовался для выбора C.
Обучение и отбор выполняются внутри CV. Предупреждений о сходимости нет.
Старый тест уже неоднократно просмотрен; результаты разведочные.
Файлы прошлой проверки сохранены в rf_comparison.
