# Что сейчас проверяется

## Третий шаг: автоэнкодер и Random Forest

Вход — 114 готовых спектральных характеристик, не сырая запись ЭЭГ.
StandardScaler приводит каждый столбец к масштабу, рассчитанному на train.
Автоэнкодер учится восстанавливать этот вектор: 114 -> 64 -> 32 -> 64 -> 114.
Тестовые строки в обучение не входят. В скрытых слоях ReLU, на выходе
линейная функция: стандартизированные значения могут быть отрицательными.

Для классификации используются значения среднего слоя из 32 нейронов.
Они становятся 32 новыми признаками для Random Forest. Сам автоэнкодер
на этом этапе учится на train обеих групп без меток. RF использует метки.
Это отличается от раннего автоэнкодера, обученного только на здоровых
и классифицировавшего по ошибке реконструкции.

32 компоненты не соответствуют напрямую 32 электродам или ритмам.
Один компонент может зависеть сразу от многих входных характеристик.

## Четвёртый шаг: общее сравнение

Внешний цикл делит 599 записей на пять частей. Одну часть оставляем для
оценки, остальные — для обучения и выбора параметров. Повторяем для всех
пяти частей, затем повторяем разбиение с другим seed. На каждом повторе
каждый участник получает одно внешнее предсказание от каждой модели.

Внутри внешнего train есть ещё три разбиения. На них GridSearchCV выбирает
параметры. Масштабирование, отбор и автоэнкодер обучаются внутри этого цикла.
Внешний test не участвует в подборе. Точные сетки записаны в protocol.json.

У двух пар записей полностью совпадают 114 спектральных значений. Одна
пара имеет разные метки. Мы сохраняем записи, но держим одинаковые профили
вместе при любом разбиении. Это предотвращает попадание точной копии входа
в обучение и тест. Причина совпадений по самому CSV не установлена.

Пять вариантов:
- Dummy: всегда предсказывает пациента, поскольку это большинство.
- L1: самостоятельная логистическая регрессия на исходных признаках.
- RF: лес на всех исходных признаках.
- L1_RF: отбор 20 исходных признаков по модулю коэффициентов и лес.
- AE_RF: автоэнкодер, затем лес на 32 латентных компонентах.

Отбор TOP-20 не означает, что все коэффициенты обязательно ненулевые.
Поэтому сохраняется их число для каждого внешнего fold.

Чувствительность — доля найденных пациентов. Специфичность — доля правильно
распознанных здоровых. Balanced accuracy — среднее этих двух долей.
F1 пациента и weighted F1 — разные показатели и не заменяют друг друга.
ROC AUC оценивает ранжирование, а не только классы при одном пороге.

## Что означают результаты

Среднее по внешним частям описывает типичное качество в этом эксперименте.
Стандартное отклонение описывает разброс между частями. Части и повторы
не независимы, поэтому SD нельзя выдавать за доверительный интервал.

Датасет и методы уже изучались до этого протокола. Даже корректная вложенная
проверка остаётся внутренним разведочным исследованием. Она не доказывает
клиническую применимость и не заменяет независимый датасет.

## Как запустить

Из корня репозитория в окружении с requirements.txt:

    python eeg_anomaly_detection/main.py audit
    python eeg_anomaly_detection/main.py rf
    python eeg_anomaly_detection/main.py hybrid
    python eeg_anomaly_detection/main.py compare
    python eeg_anomaly_detection/14_check_comparison.py

Последняя команда проверяет только завершённое общее сравнение.
Скрипт compare сохраняет завершённые folds и умеет продолжать запуск.
Если меняется протокол, нужна новая папка результатов, чтобы не смешать опыты.
